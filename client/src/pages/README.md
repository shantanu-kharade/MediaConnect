# Media-Connect

Media-Connect is a full-stack web application built using the MERN stack (MongoDB, Express, React, Node.js).

## Live Demo

🚀 **View the hosted project here:** [Media-Connect Website](https://media-connect-social.vercel.app/)

## About the Project

Media-Connect is a social platform designed to help users connect, share media, and interact with content in real-time.

### Key Features

*   **User Profiles:** Create and customize your personal profile.
*   **Media Sharing:** Upload photos and videos to your feed.
*   **Interaction:** Like, comment, and engage with posts from other users.
*   **Secure Authentication:** Safe and secure login system using JWT.

## Project Structure

The repository is organized into two main directories:

*   **`client/`**: The frontend application built with React.
*   **`server/`**: The backend API built with Node.js and MongoDB.
